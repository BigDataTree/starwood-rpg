# 星森傳說 v1.1.6：前 20 位角色行走動畫原型

此目錄包含主角四種型態及 16 位 NPC 的 64×64 四方向三幀行走 PNG（192×256）。僅這 20 個角色使用新版圖集；其他角色和怪物仍採 v1.1.6 原有美術及行為。

**品質狀態：候選原型，未完成正式美術驗收。** 核心四位 NPC 有先前四方向設計候選；其他 16 位的側面與背面主要為程式化近似稿。請勿將此批誤標為 77 位已製作完成。

整合方式：`index.html` 載入 v1.1.6 四個 game-data 區塊，在進入原遊戲前局部替換 `actorDraw`；沒有變更四個遊戲資料區塊。新圖檔會按角色顯示需求載入，載入失敗時回退到原來圖集。此設計避免改動 v1.1.6 的怪物動畫、地形碰撞、任務與商店邏輯。

注意：如果日後上傳新的根目錄 `site.zip`，既有工作流程可能重建 `index.html` 和 `assets/`，需同步更新此整合，以免被覆蓋。
